# Libarchive_oxide

Read and write archives with a Rust library and command-line tool.

## Installation

```sh
git clone https://github.com/P4suta/libarchive_oxide.git
cd libarchive_oxide
mise install rust
mise x -- cargo install --path libarchive_oxide-cli --locked
```

## Usage

```sh
oxarchive capabilities --json
```
