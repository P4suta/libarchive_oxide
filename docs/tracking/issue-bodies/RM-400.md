Campaign 4 epic and final completion gate for the Modern Replacement claim.

## Required evidence

- [ ] Portable Tier 1 codec profile is C/FFI-free by dependency-graph proof.
- [ ] Primary read/write and compatibility read-only format profiles pass their exact matrices.
- [ ] OCI and package conformance profiles pass.
- [ ] The evolving Rust API, CLI exit-code/JSON contracts, and generated support matrix are checked; SemVer and C ABI freezes are excluded.
- [ ] Three-producer/two-consumer interoperability evidence exists per format/method.
- [ ] Malformed, fuzz, resource-arithmetic, symlink-race, and decompression-bomb gates pass.
- [ ] 10 GiB streaming soak stays within the documented RSS budget.
- [ ] Native and portable performance gates pass without unapproved sustained regressions.
- [ ] Portable/native, no_std, WASI inspection, big-endian, 32-bit, MSRV, and all-features CI pass.

## Decision rule

Only after every in-scope checkbox has durable evidence may the project use
the Modern Replacement claim. Version selection, release candidates, tags,
publishing, SemVer freeze, and any C ABI remain separate future decisions.

## Current evidence gap (2026-07-28)

Deflate64 read and UDF Phase 1 are implemented, but this epic remains open.
In particular, the three-producer gate is not met for UDF (mkudffs plus two
further independently verified producers are not available in the current
environment; xorriso is ineligible because it does not produce UDF) or for
Deflate64 (the committed official 7-Zip fixture is one producer; a
redistributable Windows Explorer artifact is still missing). No release or RC
operation is authorized by this implementation.
